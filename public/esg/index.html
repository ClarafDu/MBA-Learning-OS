01 / FRAMEWORK

从导论到治理的复习轴

按参考资料顺序，从 Lecture 0 走到 Lecture 6，再查附录。点选节点看该讲的推理链，或直接检索对应条目。

    三类题怎么写

    • Single best answer · 圈出 NOT、BEST、ALWAYS，先识别题目问的是影响对象、伦理准则还是治理工具。
    • Yes / No · 首句表态，第二句给理论机制，再用题干事实解释为何成立或失效。
    • Case · 每问分别作答。用「概念 → 题干事实 → 机制 → 结论」，建议题写清责任人、措施、结果指标。
