# V1.1 产品调整说明

## 参考依据
本次参考的是可核实的成熟产品交互，而非未经验证的“排名第一”结论：
- [Notion Sidebar](https://www.notion.com/help/navigate-with-the-sidebar)：分层页面、展开/收起、集中搜索与 Home 入口。应用于课程树、Sitemap 与搜索。
- [RemNote Flashcard Basics](https://help.remnote.com/en/articles/8663109-flashcard-basics)：笔记与回忆题相连。应用于每题返回 Lecture、共享题目状态和专注复习。未引入完整间隔重复算法。
- [OpenStax Principles of Economics 3e](https://openstax.org/details/books/principles-economics-3e)：作为经济学概念页的公开教材入口。

## 设计规范
| 项目 | 规范 |
| --- | --- |
| 字体 | 系统无衬线栈，英文优先 Inter（本机可用时），中文 PingFang SC / Microsoft YaHei |
| H1 | 桌面 36px，手机 28–30px |
| H2 / H3 | 24px / 18px；复习题按可读性独立放大 |
| 正文 / 标签 / 次要信息 | 16px / 14px / 12–13px |
| 色彩 | 蓝色主操作、深蓝正文、浅灰背景、白色内容卡片 |
| 间距 | 8px 基础尺度；卡片间距 20–28px，卡片内边距 22–32px |
| 按钮 | 主要触控目标最小高度 44px |
| 导航 | 桌面课程树；760px 以下底部导航和弹出抽屉 |
| 辅助操作 | focus-visible、跳过导航、原生 dialog 焦点约束、中文折叠 aria-expanded |

## 信息架构
全站顶部提供一键中文 / English 切换，语言偏好单独保存在本机，不修改笔记和复习记录。切换使用 React 状态，不刷新页面。概念正文和用户笔记不做自动翻译。
首页 → 2026 Fall → 九门课程 → Lecture → 预习 / Student Notes / 课后总结 / Quick Review。
课程还包含概念、资料、考前复习和资源分区。
公共概念是独立 URL，可返回来源 Lecture。
My OS 提供本机笔记与备份。
Classroom 清楚标识未启用的班级权限状态。

## 验收
自动检查覆盖：进度 V1 迁移、V2 备份往返、无效导入拒绝、不同题目 ID 的队列计数、Pages 根路径与子路径，以及导出 HTML 中的链接、锚点、资源存在性。
浏览器检查覆盖：桌面与 390px / 320px 手机布局，导航抽屉、Sitemap 到课程、复习显示答案与标记、刷新后状态恢复、概念搜索和中英文展开。
本说明不宣称符合完整 WCAG 审计，也不把构建成功等同于身份验证已经实现。

双语补充验收：8 项自动测试通过；根路径与项目子路径构建均通过，23 个 HTML 页面、1678 个站内链接和资源引用检查通过。浏览器验证英文切换、跨页保留语言、刷新恢复、显示答案后切换保持当前题目，以及未保存笔记原文保持。320px 英文复习页发现的横向溢出已修复并复测；测试笔记未保存到学习记录。
