# MBA Learning OS · V1.4.0 验收说明

## 本版已完成

- Map 改为“课程—章节—概念—框架 / 案例”思维导图，支持中英切换、课程切换、概念搜索和私人笔记。
- 管理经济学、财务会计、数据/模型与决策按用户提供的课程章节设计截图校准；概念解释与案例结合本地 IMBA 课件整理。
- 六门已有资料课程共整理 82 个概念；三门暂无资料课程明确显示等待资料，不自动编造内容。
- Schedule 增加班级 Deadline 发布入口，可填写课程、类型、截止时间、要求和提交链接。
- 班级记录仍受 Supabase RLS 保护；未登录访客、未核验用户看不到班级提交链接。
- 页面、思维导图和 Deadline 表单完成 390px 手机端与 1440px 桌面端验收。

## 启用班级同步前必须完成

前端流程和 `backend/schema.sql` 已就绪，但尚未对远端数据库执行。必须先由项目所有者明确确认 Supabase 项目，再执行 schema、配置公开 publishable key、核验班级成员并完成 A/B 账号权限测试。不能把提交链接作为 GitHub Pages 的公开静态内容。

## 内容边界

课程章节设计截图只用于校准目录结构，不随公开站点上传。原始课件、作业、个人笔记和含个人信息的文件不进入 GitHub Pages。知识框架为 AI 辅助整理，原课件和页码仍是最终依据。

## 验收结果

`npm run check` 已通过：24 项单元测试、公开内容校验、ESLint、TypeScript、GitHub Pages 静态构建和 1,458 条站内链接 / 资源检查全部通过。
