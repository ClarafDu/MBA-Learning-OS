# MBA Learning OS · V1.3.0 验收说明

## 产品目标

用更少入口、更少查找时间，帮助学生不错过课程、作业与考试，并快速找到课件、知识和自己的笔记。

## 本版可用

- 一级导航仅保留 `Schedule` 与 `Map`。
- 首页直接展示下一节课、最近 Deadline 和两条功能线。
- Schedule 保留课程日历、日程补充与日历导出能力。
- Map 支持搜索、缩放、平移、课程切换、知识点定位和跨课程关联。
- Map 详情区可以查看中英双语知识解释并保存私人笔记。
- Google 翻译位于辅助工具，不再作为独立核心功能。
- 手机端提供固定的 Schedule、Map 和私人笔记入口。

## 尚未开通

- 班级课件下载需要云端存储、成员权限和资料审核流程。
- 跨设备同步需要先启用账号与云端数据库。
- Deadline 和考试时间仍需由学生或管理员补充真实数据。

界面不会把尚未开通的云端能力伪装成已经可用。
