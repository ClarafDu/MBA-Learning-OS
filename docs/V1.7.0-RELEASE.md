# V1.7.0 · Action-first Learning OS

本版不扩张功能线，重点缩短“发现任务—进入处理—找到资料”的路径。

## 用户可见变化

- 首页从宣传页调整为今日行动简报，突出未来 7 天 Deadline 与课程。
- Deadline 默认只展示逾期及未来 7 天任务，并保留全部、完成、归档筛选。
- 有提交地址的最近任务可从首页直接打开。
- Map 可按知识框架、案例正文、双语摘要和来源信息检索。
- 收紧首页卡片和移动端布局，让首屏信息密度更合理。

## 验收

- `npm run check` 通过。
- 首页、Schedule、Map 在桌面与 390px 手机视口均可使用。
- GitHub Pages 子路径 `/MBA-Learning-OS/` 的站内链接保持有效。
